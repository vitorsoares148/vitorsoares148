## 🚀 Projetos

### 🤖 Code Cross

Aplicação de análise de código utilizando Inteligência Artificial.

O usuário pode enviar código e selecionar diferentes tipos de análise, como bugs, segurança, performance, qualidade e arquitetura. A aplicação retorna um relatório estruturado com os problemas encontrados, suas respectivas linhas, explicações, sugestões de correção e código corrigido quando aplicável.

**Tecnologias:** React · TypeScript · Node.js · Express · MySQL · OpenAI API

[Repositório](https://github.com/vitorsoares148/Code-Cross)

### 📋 Muraldo

**Tecnologias:** React · TypeScript · Node.js · Express · MySQL · Jest · Supertest
